02 How it works

An investigation you can check.

The same outage, step by step: what the alarm saw, what Claude asked, what the code checked, and what came out.

Step 1

The alarm fires.

A metric stays 4σ above its normal level for 15 seconds. That part is plain statistics, no AI, so what the AI adds can be measured on its own.

Step 2

Claude investigates.

With read-only tools: metrics, logs and the call graph. Nobody tells it what broke. Every tool result gets an id like c3, so each claim it makes can be traced.

Step 3

Code checks the evidence.

A suspect counts only if a tool call it cites really showed it abnormal. Then a blast-radius check asks whether the answer explains every red service through the call graph. No second AI, no trust.

Step 4

An answer, or a human.

Verified and at least 80% confident: Sherlog answers, and drafts the ticket note for engineers and the update for customers. Anything less goes to a person.
